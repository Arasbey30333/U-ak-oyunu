# Uçak Oyunu

Bu depo, tarayıcıda oynanabilen küçük bir uçak oyunu içerir.

## Çalıştırma

1. `index.html` dosyasını bir tarayıcıda açın.
2. "Başlat" butonuna basın.
3. Sol/Sağ oklar veya `A`/`D` ile hareket edin, `Boşluk` ile ateş edin.

## Kontroller

- Sol: `A` / `←`
- Sağ: `D` / `→`
- Ateş: `Boşluk`

## Amaç

- Düşman uçakları vurun.
- Puan kazanın.
- 3 canı koruyarak en yüksek skoru yapmaya çalışın.
